# Privacy and retention

Aparté performs on-device transcription with open-source WhisperKit/Core ML. There are no analytics, account requirements, cloud inference, history database, automatic crash upload or remote support bundle. Production code does not log audio, tokens or transcripts. Dependency logging is disabled before model preparation; tokenizer parsing is local-only and receives an explicit empty credential, avoiding unrelated Hugging Face credential discovery.

Network is limited to a user-requested model download from immutable HTTPS URLs in the bundled catalog. HTTPS redirects are required. Download progress/errors contain no dictation data. Local asset hash verification precedes loading; absent/bad tokenizers fail locally rather than resolving remotely. The full base/small benchmarks and lifecycle tests run offline under process network denial, with zero intercepted HTTP(S) requests and empty benchmark stderr. See BENCHMARKS.md for limits of this evidence. Model downloads do reveal ordinary connection metadata (such as IP and requested public asset) to the host/CDN.

Microphone capture starts only after an accepted hold and permissions. It stops before inference. The tap copies bounded PCM into owned memory; there is no pre-roll or idle tap. It never writes audio to disk. Frozen audio/result buffers are released after use/cancellation. No claim is made about secure erasure of Swift/Core ML allocations, swap, system caches or OS crash diagnostics.

Only the original process/window/field identity and selection range metadata are observed. Aparté does not read surrounding document text for prompts and does not retain unrelated keystrokes. Interaction/focus changes invalidate insertion. Secure/read-only/unsupported contexts are refused or use Recovery. The app never reactivates a target or sends Return.

At most one recovery transcript is kept in process memory for five minutes; discard, a new recording, screen lock, session suspension or quit clears it. A recovery panel opened by the user can show/copy it. Explicit Copy intentionally replaces the clipboard. No transcript history is persisted in UserDefaults; preferences contain schema, shortcut, language and model identifier only.

Automatic clipboard transactions snapshot all eligible eager representations (8 MiB, 500 ms), write text plus a private transaction marker, and conditionally restore after one second only while ownership markers/content/changeCount match. Newer copies are not knowingly overwritten. Pending snapshots are memory-only and released after restore/refusal. On this OS, foreign lazy AppKit data cannot be reliably identified using public metadata: unknown nonempty clipboard contents therefore cause Recovery without fetching data (D008). The strict safety refusal is tested across two real processes.

The general clipboard is shared. Universal Clipboard and other apps may read or sync a transcript during a transaction. Temporary restoration cannot undo a read or sync, and no crash/OS-termination restoration guarantee exists. A destination such as Slack, a browser or a cloud coding tool may upload the inserted text according to its own behavior. “On-device transcription” is not a claim that text never leaves the Mac.

`artifacts/` contains local builds, public model assets, synthetic evaluation audio/results and logs, and is ignored. Committed evidence contains only original synthetic fixture outputs, timings and versions. No live/personal recordings or private transcripts were collected. The app does not request security setting changes automatically or reset TCC.
