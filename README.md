# Aparté

Native, local hold-to-talk dictation for Apple Silicon Macs running macOS 14+. Swift/AppKit menu bar app, SwiftUI settings, open-source WhisperKit 1.1.0. No account, cloud inference, persistent recording or transcript history.

**M4 candidate, not accepted.** Real offline speech inference and automated tests run on the reference Mac. Microphone/Accessibility grants, live dictation, target-app compatibility and macOS 14 runtime remain pending. Automatic adapters are disabled pending real compatibility evidence. Unknown nonempty clipboards use Recovery because macOS did not reliably expose lazy-data metadata. See [handoff](docs/HANDOFF.md), [acceptance](docs/ACCEPTANCE.md), [decisions](docs/DECISIONS.md), and [compatibility](docs/COMPATIBILITY.md).

## Build and test

Requires an arm64 Mac, Xcode (tested: 27.0 / Swift 6.4 / SDK 27.0), command-line tools selected for Xcode, Python 3 for fixture/report scripts, and network for first locked dependency resolution. No Apple Developer Program, signing identity, XcodeGen, Homebrew or hosted CI is needed. Run from the checkout:

```sh
swift package resolve
./scripts/build-local.sh --configuration Debug
./scripts/test-local.sh --suite unit
./scripts/make-fixtures.py
./scripts/install-model.sh small
./scripts/test-local.sh --suite integration
./scripts/benchmark-local.sh --manifest Tests/Fixtures/manifest.json
./scripts/build-local.sh --configuration Release
```

The checked-in project/shared scheme and both lockfiles pin dependencies. Scripts fail on errors; integration/benchmark missing prerequisites return nonzero rather than silently skipping. `artifacts/` and `.build/` are ignored. Unit tests need no model or privacy grants; they use isolated synthetic pasteboards, never the general clipboard. The tiny lazy-owner executable is compiled by the test script.

Build output: `artifacts/DerivedData/Build/Products/Release/Aparte.app`. Debug and Release use local ad-hoc signing (`CODE_SIGN_IDENTITY=-`), not Developer ID. No notarisation, DMG, release upload or remote repository is configured. `scripts/generate-project.py` updates the committed project if app source/resources change; it is not needed for a clean build.

The benchmark uses installed local macOS voices (Samantha, Daniel, Thomas, Amélie) and original text. Missing voices are a prerequisite failure; do not silently substitute a different corpus. Generated audio stays local in `artifacts/fixtures/`. The committed manifest locks references, splits and audio hashes. Voice/OS updates can change generated bytes; the script must not overwrite the locked manifest unless explicitly run with `--update-manifest` for a documented corpus revision. `APARTE_MODEL=base` selects the comparison model; it intentionally fails the technical-term quality gate. Timing is file decode only, not release-to-insertion.

## Install and first run

```sh
./scripts/install-local.sh
open "$HOME/Applications/Aparte.app"
```

Use the stable `~/Applications/Aparte.app` path. The script refuses an unrelated existing app. The local bundle identifier is `dev.aparte.Aparte`; displayed name is Aparté. Rebuild/ad-hoc identity changes can affect privacy grants: remove/re-add the app through macOS Settings if needed, quit/reopen, then Recheck. Do not reset TCC or weaken Gatekeeper/security settings.

1. Open Aparté’s menu bar item → Settings & Setup. The app normally has no Dock icon.
2. Explicitly Download the selected model, or Import a directory that matches `Resources/Models.json` including tokenizer files. Downloads are HTTPS, staged, hash-verified and atomically installed. Cancellation or failure preserves the previous installation. Prepare / Use loads the model before dictation.
3. Small is the quality-passing default on the tested synthetic corpus. Base remains selectable. Managed assets live in `~/Library/Application Support/Aparte/Models/`; Core ML may keep additional compilation caches outside this directory.
4. Enable Microphone when ready. Open Accessibility Settings and grant Aparté. Recheck. Input Monitoring is suggested only after an observed tap failure; it is not an unconditional third prompt. The status card names every missing step. Recheck restarts the listener and prepares an installed selected model; reopening after a grant/rebuild may still be needed. Clipboard event posting is checked only for paste; it does not block the microphone test or shortcut recorder. No live recording was performed by the build agent.
5. Choose Auto, English or French. The shortcut defaults to Control–Option–Space. Change it with a modifier-plus-key chord; use Test shortcut without recording. Other apps can still conflict. Launch at login is off initially and uses the actual SMAppService registration status.
6. With grants and a prepared model, hold the shortcut, wait for Recording, speak, and release. Escape cancels; 60 seconds cancels and discards. Busy holds are ignored. A new recording clears the previous recovery result.
7. Until an exact app/OS adapter has passed the compatibility protocol, open Recovery to View/Copy/Discard the result. Copy intentionally replaces the clipboard. Results expire after five minutes or on lock/quit/discard/new recording. For an unconfirmed insertion, inspect the target before copying again.

## Test Setup (0.4.1)

Quit/reopen the installed app after updating. In **Settings & Setup → Test dictation**:

- **Microphone → transcription:** click Start recording, wait for Recording, speak, then Stop & transcribe. The text appears below. Only a prepared model and Microphone access are required.
- **Shortcut → transcription → text box:** click the box, hold your shortcut, speak after Recording, and release. Keep focus in the box until insertion. Select text first to test replacement. The result reports whether the global tap or in-app shortcut handler received the chord; an in-app pass does not validate another application.
- **Preferences → Change:** the recorder takes focus and previews modifiers and the chord. Escape cancels; unsupported/reserved chords are shown without replacing the previous binding. Detection-only mode deliberately does not record; switch it off before the text-box test.

Test audio is never saved. Test results/editor clear on Setup close, explicit clear, lock/quit or five-minute expiry. General dictation remains hold-to-talk. If Needs setup persists, the status card now identifies the missing model, microphone, Accessibility or actual shortcut listener instead of a generic message.

## Privacy and limitations

Aparté originates no audio/transcript upload. Network is limited to explicitly requested model installation. Clipboard contents, Universal Clipboard, and the destination app may read, retain or sync text; restoration cannot undo those reads. No promise of secure memory erasure, protection from swap, or control over OS crash reporting. See [privacy](docs/PRIVACY.md).

Secure/password controls, read-only controls, unknown contexts, remote desktops and elevated prompts do not receive automatic text. Focus/caret changes invalidate insertion; the app never reactivates a target. It never emits Return or interprets speech as commands. Terminal custom paste handlers are outside its control. No universal atomic focus/paste/clipboard restore API exists.

The authoritative specification is [PRD v2](Aparte-PRD-v2.md). Public source/licence ownership, CI and optional distribution are owner-gated M5 work; this candidate does not begin M5.
