# Aparté

Native, local hold-to-talk dictation for Apple Silicon Macs running macOS 14+. Swift/AppKit menu bar app, SwiftUI settings, open-source WhisperKit 1.1.0. No account, cloud inference, persistent recording or transcript history.

Source is licensed under [MIT](LICENSE), with dependency and model notices in [third-party provenance](docs/THIRD_PARTY.md). [CI](.github/workflows/build.yml) builds and unit-tests on a clean arm64 Xcode 27 runner; its seven-day development artifact is ad-hoc signed and **not notarised**. See [contributing](CONTRIBUTING.md), [changelog](CHANGELOG.md) and [release tracking](docs/RELEASING.md).

**M4 implementation closed; formal acceptance pending.** The owner closed the local implementation checkpoint on 25 September 2026 with live validation still outstanding (D026). Real offline speech inference and automated tests run on the reference Mac. Version 0.5.0 organizes configuration and testing into a workspace, guided setup and compact menu companion, with the owner-selected voice-to-text logo (D031). The four pinned models retain their measured comparison; 0.4.12 added optional medium and large-v3-turbo models with an in-app measured comparison (D023–D024). Small remains the default. It also offers guarded insertion in standard editable fields across apps (D018), requests Chromium webpage accessibility (D020), returns to the original window after consulting another app (D021), and puts Recovery text on the clipboard for manual paste (D022). App-specific entries select methods; they are not an authorization list. Real external compatibility and macOS 14 runtime checks remain pending; the owner reports Setup tests working. ## Build and test

Requires an arm64 Mac, Xcode (tested: 27.0 / Swift 6.4 / SDK 27.0), command-line tools selected for Xcode, Python 3 for fixture/report scripts, and network for first locked dependency resolution. The local development signing identity is created by the setup command below; no Apple Developer Program, Developer ID, XcodeGen, Homebrew or hosted CI is needed. Run from the checkout:

```sh
swift package resolve
./scripts/local-signing.py setup
./scripts/build-local.sh --configuration Debug
./scripts/test-local.sh --suite unit
./scripts/make-fixtures.py
./scripts/install-model.sh small
./scripts/test-local.sh --suite integration
./scripts/benchmark-local.sh --manifest Tests/Fixtures/manifest.json
./scripts/build-local.sh --configuration Release
```

The checked-in project/shared scheme and both lockfiles pin dependencies. Scripts fail on errors; integration/benchmark missing prerequisites return nonzero rather than silently skipping. `artifacts/` and `.build/` are ignored. Unit tests need no model or privacy grants; they use isolated synthetic pasteboards, never the general clipboard. The tiny lazy-owner executable is compiled by the test script. For a clean checkout or CI runner without the local identity, use `./scripts/build-local.sh --configuration Release --signing adhoc`; this explicit mode does not use or replace the owner's stable local certificate.

Build output: `artifacts/DerivedData/Build/Products/Release/Aparte Dew.app`. Default local and CI builds use the development name; the beta packager explicitly requests `--variant standard`, isolated under `artifacts/StandardDerivedData/` so switching variants cannot remove the Dew app. Default Debug and Release builds use the same persistent local development certificate (D016), not Developer ID. See [local signing](docs/LOCAL-SIGNING.md) for setup, private key storage and the one-time permission transition. Direct Xcode builds require the explicit signing step; the build script performs it. A separate [self-signed beta release path](docs/RELEASING.md) signs packages locally and creates manual GitHub drafts. No public binary has been released, and notarisation remains deferred. `scripts/generate-project.py` updates the committed project if app source/resources change; it is not needed for a clean build.

The benchmark uses installed local macOS voices (Samantha, Daniel, Thomas, Amélie) and original text. Missing voices are a prerequisite failure; do not silently substitute a different corpus. Generated audio stays local in `artifacts/fixtures/`. The committed manifest locks references, splits and audio hashes. Voice/OS updates can change generated bytes; the script must not overwrite the locked manifest unless explicitly run with `--update-manifest` for a documented corpus revision. `APARTE_MODEL=base|small|medium|turbo` selects a locally installed comparison model. Base intentionally fails the technical-term quality gate. Timing is file decode only, not release-to-insertion.

## Install and first run

Default local and CI builds are **Aparte Dew**, in **Aparte Dew.app**. The local installer uses a separate path and never replaces beta **Aparte.app**. Dew uses `dev.aparte.Aparte.dew`, with its own preferences, login registration, model storage and macOS permission identity. Beta retains `dev.aparte.Aparte`. The development certificate is reused; the beta certificate is unchanged. Dew needs its own permission setup.

```sh
./scripts/install-local.sh
open "$HOME/Applications/Aparte Dew.app"
```

Use the stable `~/Applications/Aparte Dew.app` path. The script refuses unrelated apps, unsigned/ad-hoc builds, unexpected signing-identity changes and a running installed app. Quit Aparté before installing. The initial switch from ad-hoc signing uses `./scripts/install-local.sh --allow-signing-migration`; later normal updates must not need that flag. The local bundle identifier is `dev.aparte.Aparte.dew`; the local displayed name is Aparte Dew. Beta bundles keep Aparté / Aparte.app. CI artifacts also carry the Dew name. The one-time switch from ad-hoc signing may require fresh owner grants. Later builds preserve certificate-backed identity; actual permission continuity still needs live verification. If needed, re-add the installed app in Accessibility and review Microphone access through macOS Settings, quit/reopen, then Recheck. Do not reset TCC or weaken Gatekeeper/security settings.

The installer also refuses to proceed if another Aparté copy is running. A stale Debug copy under this checkout's ignored `artifacts/` directory can make its old menu bar Settings look like the installed app. `xcrun swift scripts/app-lifecycle.swift --quit-project-copies` orderly quits only those project copies; it does not force-quit or change permissions. The menu companion, tooltip and workspace title show the running version and build so you can distinguish copies.

1. Open Aparté to show the workspace. Opening it again restores that window, including when minimized. Login/service startup stays quiet; normal operation has no Dock icon. The menu bar logo opens a compact companion with status, shortcut, model, workspace and Recovery actions.
2. The first-open setup guide links **Access → Processing → Try it**. It reads actual capabilities; merely visiting a test never marks that test passed. You can hide or reopen the guide from the sidebar. Finish setup becomes available only after Microphone, Accessibility, the global listener and a prepared model are ready.
3. In **Settings**, enable Microphone when ready and grant Accessibility through macOS Settings, then Recheck. Input Monitoring is suggested only after an observed listener failure. Reopening after a grant/rebuild may still be needed. Clipboard posting capability does not block an explicit microphone test.
4. In **Processing**, explicitly Download a model or Import a matching manifest-backed directory, then Prepare / Use. Small remains recommended; base, medium and large-v3 turbo are available. Previewing a different selection does not change the active model. The previous working model survives a failed switch. Choose Auto, English or French here. [MODEL-COMPARISON.md](docs/MODEL-COMPARISON.md) explains the synthetic measurements. Dew models live under `~/Library/Application Support/Aparte Dew/Models/` (beta uses `Aparte/Models/`); use Import to copy a matching existing model into Dew without downloading again; Core ML may keep other compilation caches.
5. In **Shortcuts**, record a modifier-plus-key chord, release it, review it and **Save shortcut**. Cancel preserves the previous binding. Use default also presents a candidate before saving. Detection mode reports press/release without opening the microphone. Fn/Globe and modifier-only bindings remain unsupported; no keyboard settings are changed. Other apps can still conflict.
6. In **Try it**, run a microphone check or use the app-owned text box. When recording, wait for Recording before speaking. Outside Aparté, click your destination editable field, hold the shortcut and release to transcribe. Escape cancels; the 60-second limit cancels and discards. Busy holds are ignored. No Return is sent.
7. You may consult another app while speaking. Aparté requests one return to the original window and inserts only after verifying the same field and selection. If insertion cannot be proven, Recovery holds text and places it on the clipboard for manual paste. An unconfirmed insertion may already have inserted text: check the target before pasting again. Aparté clears Recovery after five minutes, lock, quit, discard or the next recording; the clipboard may retain or sync it longer.

## Try it

- **Microphone check:** Start recording, wait for Recording, speak, then Stop & transcribe. The real input device, received duration and live level appear during the check. Sound Input Settings opens macOS input selection. Only a prepared model and Microphone access are required.
- **Compare your accent:** Prepare / Use a model in Processing, then say the same phrase in Try it. Copy your own temporary results if you need a lasting comparison; Aparté saves no recordings or history.
- **Try your shortcut:** click the box, optionally select text, hold the saved shortcut and release. Keep focus until insertion. The result identifies global or in-app delivery. An in-app pass does not validate another app.
- **Retention:** leaving Try it or closing the workspace cancels an active local test and clears its editor/results. Explicit clear, five-minute expiry, lock and quit also clear tests. Navigating the workspace does not cancel an external dictation transaction.

## Privacy and limitations

Aparté originates no audio/transcript upload. Network is limited to explicitly requested model installation. Clipboard contents, Universal Clipboard, and the destination app may read, retain or sync text; restoration cannot undo those reads. No promise of secure memory erasure, protection from swap, or control over OS crash reporting. See [privacy](docs/PRIVACY.md).

Secure/password controls, read-only controls, unknown contexts, remote desktops and elevated prompts do not receive automatic text. Changes to the original field/caret invalidate insertion. Aparté can request one return to the original window after transcription; macOS may decline, and the exact field must still pass revalidation. It never emits Return or interprets speech as commands. Terminal custom paste handlers are outside its control. No universal atomic focus/paste/clipboard restore API exists. Recovery intentionally replaces the clipboard with the transcript when possible, so prior clipboard data may no longer be available.

The authoritative specification is [PRD v2](Aparte-PRD-v2.md), including the owner-approved amendments, unified UX and M5 scope. [Post-M5 dictation UX](docs/POST-M5-DICTATION.md) saves the deferred double-tap and optional voice-command/provider/prompt scope against the current workspace; those features are not implemented. M5A publishes source and automated builds. D030 adds separately signed experimental beta packaging; M4 real-device acceptance and downloaded beta validation remain pending. Developer ID/notarised distribution is deferred.
